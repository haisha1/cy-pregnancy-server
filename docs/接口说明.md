# 用户服务接口说明

当前以 Controller、DTO 和 local profile 的运行时 OpenAPI 为准，不保留过期导出 JSON。

| 接口 | 鉴权与行为 |
| --- | --- |
| GET /api/v1/capabilities | 公开能力清单，不代替健康检查 |
| POST /api/v1/auth/wx-login | 真实微信 code + installationId，建立会话，不上传健康数据 |
| POST /api/v1/auth/refresh | 轮换 refresh token；客户端必须串行刷新 |
| POST /api/v1/auth/logout | Bearer，撤销当前会话 |
| GET /api/v1/me | Bearer，最小账号资料 |
| POST /api/v1/me/profile | Bearer，JSON 或 multipart 更新昵称/私有头像 |
| DELETE /api/v1/me/profile | Bearer + revision，清除可选昵称头像资料 |
| GET /api/v1/me/avatar | Bearer，当前账号私有头像，不缓存 |
| GET /api/v1/knowledge | 游客只读，返回当前已发布内容 |
| GET /api/v1/knowledge/{uuid} | 游客只读，下架后不可继续读取 |
| /internal/admin/* | 管理服务匿名用户只读查询，独立服务间密钥，不暴露公网 |
| GET /actuator/health | 基础健康状态，供容器检查 |

登录请求包含 code 和 installationId，后者为 16–64 位 ASCII 字母、数字、下划线或连字符；推荐 UUID。返回业务 accessToken 和 refreshToken，业务请求使用 Authorization: Bearer，不使用 openid/session_key 作为令牌。

访问令牌默认 15 分钟，刷新会话绝对有效期默认 30 天；以配置为准。刷新令牌一次性轮换，重复使用触发重放保护；响应丢失后不盲目重放，重新登录。退出、账号状态及会话以数据库为权威。

local 开放 /swagger-ui/index.html 与 /v3/api-docs；remote、prod 关闭。401 重新登录，429 按提示重试，503 表示外部服务或依赖不可用。WX 参数未填写返回明确未配置状态，无伪造 openid 的开发后门。日志不记录密码、code、token 或正文健康数据。
